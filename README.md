Created a user-friendly book collection application utilizing the MERN stack.
• Allows a user to perform a CRUD operation on the books by creating a new book, updation, deletion, and reading existing books. 
• The data of created books is stored in the MongoDB database.
• After clicking a particular book, a new card containing all whole information about the book appears.
• Stored book data in MongoDB and used modern alert functions for better user interaction.
Project hosted using netlify and render: https://bookstoresg.netlify.app/
